# Evidence and stopping

Use this reference when Search needs to decide where to look, how far to go, or whether the inquiry has become sufficient.

## Match evidence to the question

- Current platform, API, provider, policy, law, price, or product capability: prefer current primary documentation and observed runtime behavior.
- How a mechanism works: inspect the maintained implementation or reproduce the behavior when practical.
- What a person experiences: inspect the actual artifact, flow, recording, export, or representative sample rather than relying only on feature claims.
- A creative possibility: use relevant works, demonstrations, practices, and adjacent domains; explain the transferable relationship instead of citing novelty alone.
- A user preference or authorial choice: rely on the current conversation and scoped evidence. Outside sources cannot decide it.

Search breadth and depth are independent. A narrow factual question may require deep source tracing; an open direction may need only enough range to reveal one genuinely distinct possibility.

## Keep the query open to disconfirmation

Frame a question tightly enough to be answerable without preselecting the result. “How do tools keep generated variation editable?” is useful. “Find a node editor proving we need nodes” is not.

When the current solution was introduced by the agent and governs substantial work, include evidence that could change or disconfirm it. Do not use research only to decorate a path already chosen.

## Stop according to the intent

- **Verify:** stop when the decision-relevant claim has adequate current support or the remaining uncertainty is explicit and cannot be resolved proportionately.
- **Compare:** stop when the differences that could plausibly change this choice are covered. Do not enumerate every vendor or implementation.
- **Discover:** stop when at least one concrete direction is worth making judgeable and more sources are repeating rather than changing the possibility space.

Continue when new evidence is still changing the question or the user explicitly requested broad exploration. Stop when investigation adds links but no longer changes facts, candidates, criteria, or the next useful experiment.

## Name unavailable coverage honestly

If an important channel, source, version, artifact, or observed output is unavailable, state the limitation. Do not turn “not found” into “does not exist,” or an inaccessible sample into a confident experience claim.
