# Development programme

Soundings helps an agent pursue a worthwhile inquiry to a result someone can
use: an explanation, a developed work, a grounded choice, or an authorized
change in an existing project. It should make independent investigation and
creative range available during ordinary work, while preserving the person's
intent and the momentum needed to finish.

The durable unit of growth is a **completed commission**: what consequential
work can now be done, at what quality, under which conditions? Runtime methods,
tools, research infrastructure, and a public website support that outcome.
Their existence and correctness establish their own contributions; useful
inquiry still needs to be observed in the work they support.

## Mature use

An ordinary request can start without a supplied research question or reference
list. The agent recovers the accepted goal, notices the open choice worth
investigating, encounters useful outside possibilities where relevant, reads
enough for the intended judgment, and develops the result. A consequential
finding changes the actual explanation, candidate, implementation, or acceptance
that depended on it. Later evidence can reopen that judgment without discarding
independent goals or silently replacing historical sources.

Research and understanding can also be complete outcomes. The same system should
support a precise fact check, a difficult multi-source explanation, a substantial
creative commission, and a correction inside ongoing production. Effort follows
the question and result. A settled small repair remains direct.

Search, Study, Explore, and Shape remain independently discoverable ways into
this work. Four is the current useful structure, not a permanent ceiling on
capability. Future source access, sustained research, or medium-specific tools
should earn their place through a concrete commission and its operating
conditions. Native host capabilities and existing providers remain available
composition points. A fixed pipeline or another execution runtime needs its own
evidence and product decision.

## Current construction line: evidence into judgment and revision

The source work connects a previously text-only seam: the relationship between
saved source passages, an authored explanation, counterevidence, and the later
judgments that depend on it. Study owns the interpretive method. The optional
`workpaper.py` supplies deterministic citation assembly and dependency traversal
over explicitly supplied data. Search can bring material into it; Explore can
retain reference observations and proposed transfers; Shape can use it to
locate affected conclusions before correcting the actual work.

The complete local journey is capture, author a cross-source judgment, inspect
its citations, render a readable standalone research artifact, reuse selected
sources elsewhere, and revisit declared descendants when a premise changes.
Snapshots remain source material; the workpaper remains authored interpretation.
No command treats citation presence as reading, agreement as independence,
current status as freshness, or a graph edge as permission to act. Existing
project records remain authoritative, and ordinary tasks need no workpaper.

This is supporting capability for complete inquiries. Its deterministic success
does not resolve the earlier proactive-discovery failure or establish better
model judgment. The next behavior acceptance must connect the whole scene:
useful acquisition, a qualified explanation or candidate, a changed premise,
targeted correction, and a delivered result. A separate settled task should
detect unnecessary inquiry. Any new target-model trial retains its own scope
and invocation budget.

## Continue along connected responsibilities

1. **Complete and exercise the judgment path.** Make the optional local tools
   usable through the installed method paths and maintain a worked reader
   journey. Inspect the substantive reasoning as well as mechanical links.
2. **Resolve the first missed action in ordinary work.** Use the existing
   observation tools to distinguish an unrecognized open choice, an inaccessible
   tool, a source-selection failure, and an unsupported early commitment. Change
   the implicated boundary; adding more method text is not itself a result.
3. **Develop the result in its real medium.** Carry source relationships into
   an explanation, creative work, or implementation, then inspect what the user
   can actually do. Complete the commission rather than handing back the next
   experiment or production step already authorized.
4. **Grow source capability where commissions justify it.** Corpus lookup,
   current-source verification, long-running research, and interactive reference
   observation have different needs. Add or compose a capability for an actual
   unmet task; keep account, private-data, retention, installation, and deployment
   authority explicit.

These responsibilities can overlap or recur. They are a development direction,
not a required sequence of Skills or an automatically scheduled experiment.
Research tooling is already sufficient to support a discriminating next trial;
further instrumentation should answer a specific unanswered question.

## External mechanisms considered

Reviewed on 2026-10-25. No external code or prompts were copied into the package.

| Source and observed mechanism | Disposition here |
| --- | --- |
| [Open Deep Research](https://github.com/langchain-ai/open_deep_research/blob/1b7d2e80db9faa586165c60e09096dbbfd483a64/src/open_deep_research/deep_researcher.py), commit `1b7d2e8`, MIT; `deep_researcher.py`, `prompts.py`, and `LICENSE` inspected. Researchers retain raw notes alongside compressed findings; the final writer consumes synthesized notes. The repository is archived. | **ADAPT:** preserve independently rereadable source material beside authored synthesis. Soundings uses exact local ranges and explicit links. Leave out the supervisor graph, model configuration, compression calls, retry policy, and report-ending runtime; the current host already owns execution and continuation. Static source inspection does not establish that runtime's research quality. |
| Anthropic's [research-system account](https://www.anthropic.com/research/multi-agent-research-system), published 2025-06-13: dynamic inquiry and explicit tool-selection affordances | **ADAPT:** inspect the capability needed for the current question and keep tool availability distinct from an agent's choice to use it. Leave out a fixed researcher team and production orchestration. The article's reported results are not Soundings measurements. |
| [Official OpenAI Skill guidance](https://developers.openai.com/plugins/build/skills): discoverable descriptions, conditional resources, deterministic scripts | **ADAPT:** use the script boundary for exact citation processing. Independent entrypoints and conditional resources already provide progressive disclosure. Source/content delivery still needs its own observation. |

The methods retain their own complete outcomes and domain evidence standards.
The [design](../plugins/soundings/docs/design.md),
[forward scenarios](../plugins/soundings/docs/behavior-scenarios.md), and
[host integration contract](../plugins/soundings/docs/host-integration.md) define
the respective responsibilities; none configures another host or grants new
execution authority.
