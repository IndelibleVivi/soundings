# Development programme

Soundings helps an agent pursue a worthwhile inquiry to a result someone can
use: an explanation, a developed work, a grounded choice, or an authorized
change in an existing project. It should make independent investigation and
creative range available during ordinary work, while preserving the person's
intent and the momentum needed to finish.

The durable unit of growth is a **completed commission**: what consequential
work can now be done, at what quality, under which conditions? Runtime methods,
tools, research infrastructure, and a public website support that outcome.
Their existence and correctness establish their own contributions; useful
inquiry still needs to be observed in the work they support.

## Mature use

An ordinary request can start without a supplied research question or reference
list. The agent recovers the accepted goal, notices the open choice worth
investigating, encounters useful outside possibilities where relevant, reads
enough for the intended judgment, and develops the result. A consequential
finding changes the actual explanation, candidate, implementation, or acceptance
that depended on it. Later evidence can reopen that judgment without discarding
independent goals or silently replacing historical sources.

Research and understanding can also be complete outcomes. The same system should
support a precise fact check, a difficult multi-source explanation, a substantial
creative commission, and a correction inside ongoing production. Effort follows
the question and result. A settled small repair remains direct.

Search, Study, Explore, and Shape remain independently discoverable ways into
this work. Four is the current useful structure, not a permanent ceiling on
capability. Future source access, sustained research, or medium-specific tools
should earn their place through a concrete commission and its operating
conditions. Native host capabilities and existing providers remain available
composition points. A fixed pipeline or another execution runtime needs its own
evidence and product decision.

## Current construction line: a connected local inquiry

The `0.7.0` construction connects explicit acquisition, reading progress,
results and feedback inside ordinary host work. An optional workspace reuses
existing evidence snapshots and retains the current question, next action,
settled choices, unread/blocked leads, only the line ranges actually returned,
exact result versions and feedback tied to those versions. Resume and explicit
fork make that working material available after interruption or relocation.
The conversation remains the main entry; the existing project record retains
accepted-decision authority.

Known public text URLs can be acquired with a bounded direct GET. Decoded
response text stays beside separately labelled HTML extraction. Host search,
connectors, document readers and original-medium observation remain available
composition points; the workspace does not turn every medium into text or
pretend literal corpus search is semantic retrieval. Acquisition failures and
unread leads remain visible.

A complete result is registered as the actual file, not merely a judgment
saying it exists. Feedback names its result version; a later disposition points
to a real successor after the actual deliverable has been revised. Tool-level
history, descendant validation and restored reading extent do not establish
understanding, semantic correction, author satisfaction or causal benefit.

The earlier workpaper and packet construction remains usable: exact source
ranges, authored findings and counterevidence, two-revision comparison with
separate old/new dependency paths, and an explicit portable earlier basis.
No record is migrated and no new synthesis format replaces it. Ordinary work
need not create a workpaper or workspace.

Behavior acceptance must exercise both explanation and creative delivery,
including useful outside acquisition before commitment, interruption, changed
evidence or feedback, preservation of independent requirements and an actual
completed result. A settled small task detects unnecessary inquiry. Historical
failed proactive discovery stays failed at its original scope; a new bounded
trial cannot establish cross-model superiority. Exact current checks and trial
results belong in [current state](current-state.md).

## Continue along connected responsibilities

1. **Resolve the first missed action in ordinary work.** Use the existing
   observation tools to distinguish an unrecognized open choice, an inaccessible
   tool, a source-selection failure, and an unsupported early commitment. Change
   the implicated boundary; adding more method text is not itself a result.
2. **Use the continuation path in complete commissions.** The local path now
   supports an explicit authored handoff, a separate working revision and review
   of earlier grounds. Exercise whether that support improves a substantial
   explanation or authorized correction, including its actual deliverable.
   Inspect reasoning and acquisition as well as mechanical links. Ordinary work
   need not acquire a workpaper; adding another record format is not the next
   default construction step.
3. **Develop the result in its real medium.** Carry source relationships into
   an explanation, creative work, or implementation, then inspect what the user
   can actually do. Complete the commission rather than handing back the next
   experiment or production step already authorized.
4. **Grow source capability where commissions justify it.** Corpus lookup,
   current-source verification, long-running research, and interactive reference
   observation have different needs. Add or compose a capability for an actual
   unmet task; keep account, private-data, retention, installation, and deployment
   authority explicit.

These responsibilities can overlap or recur. They are a development direction,
not a required sequence of Skills or an automatically scheduled experiment.
Research tooling is already sufficient to support a discriminating next trial;
further instrumentation should answer a specific unanswered question.
