# 0.4.0 candidate observations

Observed on 2026-10-21. This is a bounded source-catalog comparison, not an installed-plugin acceptance record.

**The proactive-discovery criterion failed in the candidate's open task.** The candidate read the revised engineering and creative methods, then selected and implemented a direction without inspecting external references. Both versions produced functioning local artifacts. The two small repairs stayed direct. These observations do not establish a behavior improvement.

## Conditions

Four independent fresh ACP sessions used the same configured `dsf` model and harness. The adapter requested and advertised `9router/dsf`; the underlying provider identity was not independently verified. There was one run per condition, no corrective model turn, and no separate judge-model invocation.

The baseline used Soundings source at `3619a1b` and Servotab source at `959823e`. The candidate used the `0.4.0` Soundings methods and the companion Servotab router/Design source changes. Each session received a local catalog of descriptions and readable source paths, rather than an explicit Soundings invocation. The runtime method snapshots were compared byte for byte with the candidate source after the runs.

The comparison changes both packages together. It cannot attribute a difference to Soundings, Servotab, their interaction, or one particular clause. A source catalog in this harness also does not establish ordinary Codex marketplace discovery or activation.

The task inputs were constructed. Both open tasks began with the same small browser-local reading desk: three fictional attributed texts, source selection, per-source notes, local persistence, and three contract tests. Both small tasks began with the same original version. The tasks used no private research material or real user study, and performed no account action, deployment, or additional paid-service integration.

The ordinary open prompt asked to continue developing the reading desk so it better supported writing from several texts, and to deliver a runnable next version. It supplied no reference, search term, diagnosis, or prescribed workflow. The small prompt asked only to rename the sidebar's `Library` label to `Sources`, including its accessible name and corresponding assertion.

The candidate did not read Search's proactive-inquiry reference. Its initial local inspection correctly recognized an open writing experience, but the next consequential step was to choose the three-view design and begin implementation. The new cue therefore reached the session without producing its required outward observation. This distinguishes a failure to act on delivered guidance from a claim that the package was entirely invisible.

Both versions retained source attribution and local-only data behavior. The candidate's explicit passage-to-draft insertion was a useful concrete interaction in the inspected scene. It was not derived from observed external evidence, and one different artifact cannot establish that the method caused a better result. More views, references read, tests, or prose are not benefit measures.

## Verification of the artifacts

The coordinator independently reran the resulting tests: 13 passed for the baseline open artifact, 15 for the candidate open artifact, and 3 for each small repair. These are different generated test suites, not a comparative quality score.

The model workers did not complete real-browser verification in their execution environment. A separate coordinator check used bundled headless Chromium and exercised both open artifacts:

- select passages from two sources and edit a source note;
- develop a draft, with attributed insertion where the artifact supported it;
- reload and observe persisted draft content and retained passages;
- download and inspect Markdown with the source attribution;
- inspect desktop and 390-pixel layouts, with no horizontal overflow or browser console errors in that scene.

This confirms that the inspected paths operated. It is not human acceptance, a full accessibility audit, or proof of all recovery behavior. Clipboard copying was not separately exercised. Coordinator verification is not counted as autonomous model verification or another model run.

The small-task pair also shared an explicit browser-safety constraint, added before either small session started after the open runs exposed unsuitable browser-launch attempts. Neither small task required browser use. This limits comparisons of whole-run behavior across the two different task types; the instructions within each baseline/candidate pair remained matched.

## Source checks

All four Soundings Skill validations, plugin JSON syntax, the 35 deterministic helper tests, documentation links, and diff checks passed. The companion Servotab candidate passed generated sync, thirteen-skill validation, seventy-file package identity, packaging selftest, 94 Python tests, public-tree audit, compilation, and the no-target-model Field Lab checks.

These checks establish source/package consistency. They do not turn the failed discovery observation into a pass.

## Consequence and remaining gate

Keep `0.4.0` labeled as a source candidate. The small-repair boundary worked in these two observations; proactive discovery at an open choice did not. Receiver-side continuation after actual external findings, multiple named targets, repeated rejection, and other forward scenarios remain behaviorally untested for this candidate.

The next useful diagnosis concerns the transition from a delivered open-choice cue to the first design commitment. Simply adding longer descriptions, counting method reads, or changing models would not establish a repair. Any further model comparison needs its own scope and invocation budget; this record used all four authorized runs.

No candidate installation, fresh installed-host activation, tagged release, website deployment, cross-model comparison, causal benefit, or broad scenario coverage is claimed. Raw traces, generated task workspaces, and browser artifacts remain private and outside Git. Historical [0.3.1 observations](dogfood-0.3.1.md) keep their original scope.
